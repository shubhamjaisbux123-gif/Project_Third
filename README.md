Why we use this program

Without a program like this, you'd have to remember every purchase, do your own math to find totals, and keep everything organized by hand (in a notebook, memory, or a spreadsheet you update yourself). That's slow and easy to mess up.

This program does three things for you automatically:

Records — every expense gets saved with today's date, category, and amount, so nothing is forgotten.
Stores — it keeps everything in a file (expenses.csv) that doesn't disappear when you close the program.
Calculates — it adds up totals per category instantly, instead of you doing the math yourself.

So the real-world use case is: you run it, log your expenses as you spend money, and anytime you want to know "how much did I spend on food this month?" or "what's my total spending?", the program tells you instantly instead of you digging through receipts or bank statements.


In short: to track spending automatically instead of manually.
